# 学生管理系统使用说明

本系统通过浏览器管理学生、课程和选课，数据保存在本机 MySQL 中。

## 启动与停止

用 VS Code 打开 Student-Web 文件夹，在终端输入：

```powershell
.\start.ps1
```

输入本机 MySQL root 密码后，浏览器会自动打开。保持启动终端打开；按 Ctrl+C 停止服务。

| 项目 | 内容 |
|---|---|
| 网页地址 | http://127.0.0.1:5178 |
| 网页账号 | demo_admin |
| 网页密码 | Demo12345! |
| Java 后端地址 | http://127.0.0.1:8088 |
| MySQL 数据库 | student_web_demo_20261010 |

网页账号与 MySQL 账号是两套账号。网页登录使用 demo_admin；启动终端输入 MySQL root 密码。MySQL 密码不写入代码或配置文件。

修改代码后，先停止服务，再执行启动脚本重新构建。网页当前使用构建版本，编辑源码不会立即更新页面。

## 导入班级学生和课程

先启动系统，再在另一个项目终端输入：

```powershell
.\import-school.ps1
```

脚本读取指定的 2026 春季班级课表与 2025 级综测表，匹配班级后导入学生和课程。重复执行会跳过已有记录，已有数据不被覆盖。

本次导入包含 18 个班级、864 名学生和 27 门课程。2025 级软件工程 4 班有 44 名学生。首页人数还包括之前保留的练习记录。

| 系统字段 | 导入方式 |
|---|---|
| 姓名 | 使用名单中的姓名 |
| 邮箱 | 按学号@lingnan生成，用作本机系统的邮箱字段 |
| 班级／院系 | 使用名单中的完整班级名称 |
| 课程名称 | 从班级课表中提取并去重 |
| 课程编号 | 自动生成本机管理编号，不是学校官方课程代码 |
| 学分、出生日期 | 源资料未提供，留空 |
| 个人选课、课程成绩 | 未提供个人明细，需手动登记 |

综测分数与排名不作为课程成绩导入。课表中的上课周次、地点和教师目前没有对应管理界面。

导入前的记录保存在 .runtime/school-import-before.json；导入报告和本次新增的记录编号保存在 .runtime/school-import-report.json。需要撤销学生导入时，可以依据报告中的编号执行软删除，再通过回收站恢复。

## 功能与操作

| 菜单 | 功能 |
|---|---|
| Dashboard | 查看真实学生数、课程数和宽幅班级人数分布图 |
| Students | 添加、查询、编辑学生，删除记录，上传照片和导出 CSV |
| Courses | 按专业、班级逐层查看课程，也可查看全部课程、添加课程 |
| Enrollments | 管理个人选课 |
| Recycle bin | 查看和恢复被删除的学生 |
| Export | 导出学生数据 |

添加学生：进入 Students，点击 Add student，填写 Name（姓名）、Email（邮箱）、Department（班级／院系），点击 Create。刷新后记录仍保留。

修改学生：点击学生行的编辑按钮，修改字段后保存。
删除学生：点击删除按钮，确认后进入回收站；需要恢复时进入 Recycle bin。

课程浏览：先点击专业卡片，再点击班级卡片，即可看到该班课表中的课程。点击顶部路径可返回上一级；每层使用“上一页”“下一页”翻页。点击“全部课程”查看完整目录，新增课程也在完整目录中显示。

专业、班级与课程的关系来自导入资料；重新执行导入脚本时更新分类目录。页面分类人数依据源名单，首页人数依据当前有效记录。课表中的课程安排不等于个人选课记录。

课程没有学分时显示“未提供”。首页已删除平均年龄、空选课趋势和模拟增长率，没有为它们添加替代模块。班级标签使用加深的原色背景和黑字。

当前姓名搜索可用；邮箱搜索与单独按班级筛选尚需完善。角色页面、图片上传和个人选课等额外流程仍需逐项练习和核验。

## 程序与数据库的关系

浏览器发送请求给 Java 后端，Java 后端连接本机 127.0.0.1:3306 的 MySQL 并保存数据。DataGrip 可以连接同一个 MySQL 查看数据。

系统仅供本机访问，不需要开启上网代理。原始名单和课表保持不变。
